# ADR-001: Elecció de la base de dades

## Context
El projecte necessita emmagatzemar productes, usuaris i comandes amb estructures flexibles i relacions no rígides. A més, volem una base de dades que s’integri bé amb Node.js/Express i que sigui fàcil de desplegar en entorns Docker.

## Decisió
S’utilitzarà **MongoDB** com a base de dades principal del projecte. La instància s’executarà mitjançant **Docker**, utilitzant un contenidor dedicat i una xarxa interna per comunicar-se amb el backend.

## Conseqüències
**Positives**
+ Flexibilitat per afegir nous camps i entitats sense modificar esquemes rígids.
+ Integració excel·lent amb Node.js a través de Mongoose.
+ Facilitat de desplegament amb Docker i compatibilitat amb MongoDB Atlas.

**Negatives**
- Menys adequat per a consultes molt relacionals.
- Pot requerir optimitzacions addicionals per a consultes complexes.
