# ADR-002: Estructura inicial del projecte

## Context
El projecte E-commerce Full Stack inclou un frontend en React i un backend en Node.js/Express. Cal decidir si mantenir-los en un **monorepo** o en **repos separats**, tenint en compte la gestió del codi, la col·laboració i el desplegament.

## Decisió
S’opta per **repos separats**: un repositori per al backend i un altre per al frontend. Cada part del projecte tindrà el seu cicle de versions, dependències i desplegament independent.

## Conseqüències
**Positives**
+ Major claredat en la gestió del codi.
+ Cada equip o mòdul pot treballar de manera independent.
+ Menys conflictes de dependències entre frontend i backend.
+ Facilita desplegar cada component per separat.

**Negatives**
- Cal gestionar dos repositoris en lloc d’un.
- Algunes automatitzacions (CI/CD) poden requerir configuracions duplicades.
