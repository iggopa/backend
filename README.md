## Execució del projecte
- npm install
- Creem un arxiu .env
- PORT=5000
- MONGODB_URI=mongodb://localhost27017/backend
- JWT_SECRET=constrasenya
- npm run dev
- mongod
- docker build -t backend .
- docker run -p 5000:5000 backend
